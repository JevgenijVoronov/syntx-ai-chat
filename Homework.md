## Тестовое задание: Простое приложение "Чат" на Vue 3

**Цель задания:**
Проверить умение работать с Vue 3, организацией компонентов, state management (Pinia), маршрутизацией (Vue Router) и использованием UI-фреймворка.

### Описание приложения

Разработайте простое SPA-приложение "Чат" со следующей структурой:

1. **Сайдбар со списком чатов**

   - Слева должен располагаться список чатов (например, 3-5 заранее заданных чатов).
   - При клике по чату должен меняться основной URL (/chat/:id), а в основном окне отображаться выбранный чат.
   - Активный чат должен визуально выделяться.

2. **Окно выбранного чата**
   - В основной части страницы отображаются сообщения выбранного чата.
   - Должна быть форма для отправки текста нового сообщения.
   - После отправки сообщение появляется в текущем чате.
   - Для реализации требуется хранение сообщений в состоянии frontend’а (например, Pinia).

### Требования к реализации

- Используйте **Vue 3** и **Composition API**.
- Используйте **Vue Router** для навигации между чатами.
- Для управления состоянием используйте **Pinia** (например, хранение списка чатов и сообщений).
- Для стилизации и UI-элементов подключите один из популярных UI-фреймворков (например, Element Plus, Vuetify, Naive UI и др. — на ваш выбор).
- Структурируйте приложение с использованием отдельных компонентов (Sidebar, Chat, Message, Input и др.).
- Реализуйте базовую валидацию формы ввода (например, не разрешать отправку пустого сообщения).
- Реализовать псевдо-асинхронность так будто данные получаются и отправляются на сервер (например, с помощью setTimeout).

### Бонусные задачи (по желанию)

- Добавьте возможность создавать новые чаты.
- Реализуйте примитивную "псевдо-бот-логику" — автоматический ответ от бота через 1-2 секунды после сообщения пользователя.
- Внедрите composable функцию. Например для работы с компонентом сообщений от юзера и бота.
- Оптимизация рендеринга сообщений или списка чатов (например, с помощью виртуального скролла).
- Используйте provide/inject и динамические компоненты. Например создайте компонент табов для разделения списка чатов: все и избранные.
- Разместить проект на GitHub и написать небольшой CI/CD скрипт для проверки lint, build проекта и деплой на любой бесплатный хостинг (например, Vercel, Netlify и др.).
